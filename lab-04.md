# Лабораторная 4. Генерация изображений и HTTP

[К оглавлению](README.md)

Смысл: сформировать запрос к генератору, получить результат, сохранить и показать изображение.

## Вопросы из обсуждения защиты

### Чем код генерации текста отличается от генерации картинки?
На уровне API оба обычно отправляют HTTP-запрос с параметрами модели. Но схема запроса и обработка ответа отличаются: текстовый API возвращает сообщения/текст, генератор — URL, Base64 или байты изображения. Изображение нужно декодировать либо скачать и сохранить; точная схема зависит от сервиса.

### Как сделать без LangChain?
Напрямую через requests или SDK сервиса: сформировать заголовок авторизации и тело, выполнить POST, проверить статус и разобрать ответ.

```python
# Условный текстовый endpoint; точные поля берём из документации сервиса.
response = requests.post(base_url + '/chat/completions',
    headers={'Authorization': f'Bearer {key}'},
    json={'model': text_model, 'messages': [
        {'role': 'user', 'content': 'Объясни задачу'}]}, timeout=60)
response.raise_for_status()
answer = response.json()['choices'][0]['message']['content']
```

### Почему после POST используется GET?
POST запрашивает генерацию. Если ответ содержит сетевой URL картинки, GET скачивает уже созданный файл: `requests.get(item['url'])`. GET не генерирует картинку повторно.

### Что фактически возвращает POST? Как выглядит JSON?
HTTP-ответ содержит статус, заголовки и тело. JSON — возможный формат тела, не весь HTTP-ответ. Пример схемы: `{'data': [{'url': 'https://host/path?...'}]}` либо `{'data': [{'b64_json': '...'}]}`. URL не обязан оканчиваться .png; формат определяется содержимым и Content-Type.

### Всегда ли приходит ссылка на картинку?
Нет. В одном из наших реальных ответов картинка пришла в `message.images[0].image_url.url` как `data:image/png;base64,...`, а content был null. Data URL содержит сами закодированные байты; скачивать его HTTP GET не нужно. Это наблюдение одного провайдера, не универсальная схема.

### Что нужно показать в лабораторной?
Фактический JSON конкретного ответа. Огромную Base64-строку можно сократить для чтения, сохранив структуру и указав, что поле сокращено. Не заменять ответ вымышленной схемой и не выводить ключ.

## Дополнительные вопросы для подготовки

### Почему файл .png может не открываться?
Расширение не меняет формат байтов. У нас сервис возвращал WebP в файле с расширением .png. Нужно декодировать и пересохранить в PNG либо правильно указать MIME и расширение.

### Что меняет LangChain?
Упрощает шаблоны, сообщения и композицию вызовов, но сетевой запрос всё равно выполняет клиентская библиотека. Принцип передачи данных остаётся тем же.
