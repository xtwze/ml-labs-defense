# Код лабораторных №3–13

Каждая работа — отдельный `lab-NN.ipynb`. Файлы с вопросами находятся [в корне репозитория](../README.md).
В публичной копии очищены результаты выполнения и настройки локального ядра: выполните ячейки сверху вниз.

## Запуск

Откройте папку `code` в Jupyter или PyCharm и используйте Python 3.12.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m ipykernel install --user --name ml-labs --display-name 'Python (ML labs)'
```

Выберите установленное ядро. Зависимости должны быть установлены именно в Python выбранного ядра.

Для лабораторных 3–11 нужен собственный ключ RouterAI. Перед запуском Jupyter задайте
переменную `ROUTERAI_API_KEY` либо создайте в `code` локальный `.env`:

```dotenv
ROUTERAI_API_KEY=your_key_here
```

Вызовы платные по тарифам выбранного провайдера. Модели и их доступность могут меняться;
текущие имена находятся в `lab_runtime.py` и ячейках соответствующей работы.
Ноутбук 8 — вариант через RouterAI с русскими комментариями.

Для работы 12 дополнительно:

```bash
python -m pip install -r requirements-local-models.txt
```

Работа 12 использует локальные веса из Hugging Face, скачиваемые при первом запуске.
Для llama-cpp-python может потребоваться компилятор C/C++; для macOS — Command Line Tools.
После скачивания модели выполняются локально. Отдельный облачный ключ не требуется.

Для работы 13:

```bash
python -m pip install -r requirements-lab13.txt
```

Данные включены в `assets/lab13`. Это экспорт открытого набора
[ex3data1.mat](https://github.com/dibgerge/ml-coursera-python-assignments/tree/master/Exercise3/Data)
в TXT, а не подтверждённая копия файлов преподавателя. Обучение реализовано на NumPy;
SciPy для запуска опубликованного ноутбука не нужна.

## Устройство

- `lab-03.ipynb` — промпты и температура.
- `lab-04.ipynb` — генерация изображений и формат ответа API.
- `lab-05.ipynb` — история и диалог двух агентов.
- `lab-06.ipynb` — последовательные цепочки и контекст.
- `lab-07.ipynb` — Vision и условная генерация.
- `lab-08.ipynb` — объекты, сравнение сцен, коллаж и стили.
- `lab-09.ipynb` — распознавание и синтез речи.
- `lab-10.ipynb` — RAG с BM25 и перефразировками.
- `lab-11.ipynb` — инструменты, ручной агент и LangGraph.
- `lab-12.ipynb` — Transformers и llama-cpp-python.
- `lab-13.ipynb` — логистическая регрессия для рукописных цифр.
- `lab_runtime.py` — общий клиент API и подготовка медиа.
- `assets` — данные 13-й работы и схема графа 11-й; остальные медиа создаются при выполнении.

В работе 11 инструмент письма сохраняет `.eml`, внешняя доставка не выполняется.
Примеры 3–11 могут создавать локальные файлы, выполнять сетевые запросы и повторно использовать кеш.
Опубликованные исходники проверены на корректность формата и синтаксиса; полный повторный платный
прогон всех работ при подготовке этой публичной копии не выполнялся.
