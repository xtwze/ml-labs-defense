Формулировки пересказаны по заметкам и диалогам, это не дословная стенограмма и не официальный перечень преподавателя. В разделах явно разделены вопросы из обсуждений и дополнительные вопросы. Для №10 конкретные вопросы преподавателя не были записаны. Вопросы про цепочки, Vision и агентов иногда обсуждались без точного номера, поэтому распределены по теме. Утверждать, что преподаватель задал каждый пункт, нельзя.

## Как готовиться

Начните со смысла работы и вопросов из обсуждения. Для каждой операции объясните вход, выход, исполнителя (Python, библиотека или модель) и конкретное место в коде. Затем переходите к уточнениям и ограничениям. Не называйте вероятность токена вероятностью истинности, сохранённый файл письма доставкой, а наличие истории гарантией правильного ответа.
